Vyber ročník a sestav samostatný soubor pro vlastní server. Obsahuje mapu i histogram, vlastní JavaScript a CSS, data, výsledky a případně fotografie. Po sestavení již nepotřebuje tento server ani GitHub.

Stáhnout samostatné HTML

Leaflet a jeho styl se nadále načítají z CDN unpkg.com, mapové dlaždice z tile.openstreetmap.org. Nejde tedy o plně offline mapu. Export spouštěj přes HTTP/HTTPS. Výsledný soubor vyžaduje moderní prohlížeč s podporou import maps; server nesmí blokovat vložené skripty, styly, srcdoc rámce a blob moduly přísnou CSP.
